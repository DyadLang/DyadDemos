# Linear Actuator System 

1. Read the model in this repository. 
2. Find an appropriate trim point for this model.
3. Linearize the model about this trim point, and produce bode plots and root locus plots
4. Tune the cascaded controller in this example, using the DiscreteAutoTuningProblem, in a julia script. 
5. Apply the tuned gains to the system and produce disk margin plot for this closed loop system.
